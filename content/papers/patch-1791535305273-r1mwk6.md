## 01 论文基础信息

- **论文标题：** 对patch的研究

## 02 论文要解决的核心问题

patch操作：筛选、剪枝、合并、增强、重写、跨尺度融合，甚至保留一组 Patch Tokens，让查询图像和数据库图像的 Patch 直接进行匹配

## 03 核心解决方案

#### 细粒度图像检索的 Patch 操作：
- SwinFGHash（2021）
学习多个具有不同显著性的局部区域，学习多个局部显著性图，设计了GwL模块。具体操作：提取patch，patch merging，学习K个局部显著性图，每张图为不同patch分配权重，再与原patch特征逐元素相乘，最后对全局特征和多个局部特征进行transformer特征细化，组合成最终表示，并通过哈希学习生成检索编码。
- DVF（2024）
通过语义重要性筛选 Patch。先让目标占据更大的有效图像区域，再从patch中挑选有判别力的局部信息。具体操作：使用Grounding DINO 根据元类别的文本提示定位目标，通过裁剪和适当扩展框来突出目标，减少背景干扰。利用 CLS Token 的注意力分数反映不同 Patch 的语义显著性。将每个 Patch 特征输入线性映射和 Sigmoid，生成一个额外的重要性分数。将 CLS 注意力与额外的重要性分数结合，筛选判别性 Patch，降低背景和无关区域的影响。
- EET（2025）
内容感知的分层 Patch 剪枝。细粒度检索需要关注很小的局部差异，但普通 ViT 会反复计算大量背景或低判别性 Patch。它提出 Content-based Token Pruning（CTP），再利用蒸馏维持剪枝后的细粒度判别能力。在 Transformer 的多个层提取多头注意力中的中间 Token 内容。
根据每个注意力头产生的 Token 内容向量的 L2 范数计算响应强度。将不同注意力头的响应强度归一化，作为不同注意力头的权重。将这些权重与 CLS 对各 Patch 的注意力结合，得到更有针对性的 Patch 重要性分数。在第 4、8、10 层执行分层剪枝，只让保留下来的 Token 进入后续层。此外，EET 通过 Discriminative Knowledge Transfer 和 Discriminative Region Guidance，将较大教师模型的判别知识和关键区域信息传给剪枝后的学生模型。最终检索哈希码由 CLS 表示生成

#### 超出常规池化的 Patch 局部匹配与重排序，不一定把全部patch聚合成一个全局向量，而是保留局部信息，在查询图像与候选图像直接计算patch匹配关系
- CraterBench-R（2026）：
论文研究发现单一全局向量会丢失细小的空间结构，于是直接保留多个 ViT Patch Tokens，用 Late Interaction 计算查询图像和候选图像之间的相似度。具体操作：对于查询图像中的每个 Patch，找到数据库图像中与它最相似的 Patch，然后将这些最大相似度求平均，这意味着：不用先将每张图像的全部 Patch 压成一个向量，而是允许不同图像的局部区域独立建立匹配。作者又提出 Instance-token Aggregation，将大量 Patch 压缩成较少的代表性 Token：选择 K 个种子 Token，可根据 CLS 注意力选取高显著性 Token，也可使用最远点采样（FPS）选取具有多样性的 Token。将剩余 Patch 分配给特征空间中最相似的种子 Token。将每个种子与分配给它的 Patch 特征均值相加，再进行 L2 归一化。
相比单纯采用聚类质心，种子残差形式会保留一部分种子自身的细节。整个压缩步骤不需要额外训练。论文报告，使用 16 个代表性 Token 时，mAP 相比直接选取相同数量的原始 Token 提高了 17.9 个百分点；使用 64 个 Token 时，效果可以接近使用全部 196 个 Patch Tokens。
